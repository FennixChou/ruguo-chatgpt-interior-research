# 02／04（及 03）知識檔增補清單

用途：兩份 2026-08-19 研究報告（①提升 ChatGPT 室內設計生圖能力／②讓 ChatGPT 把平面圖變 3D 立體圖）裡，發現現行 02_知識檔_材質與工法詞彙表、04_知識檔_風格定義兩份正本尚未收錄、但實測會用到的英文詞彙。列出後可直接套進兩檔對應段落；**格式：檔｜段落｜新增內容｜來源**。

一條條目原則上只認定一個目標檔，但等角／剖視類視角詞是模式二（平面圖→3D）的專屬詞彙，性質上更接近「鏡頭幾何」而非「材質」或「風格」，本清單同時列出建議放進 03（台灣住宅尺度與鏡頭幾何）而非硬塞進 02／04，避免把不相關的詞混進材質表或風格表——這點在套用前請老闆先確認要不要照建議調整目標檔。

本清單只列「新增什麼」，不動兩檔既有內容；套用方式＝人工複製貼上到對應檔案的對應段落，不是自動覆蓋。

## 四、暫不收錄項（供老闆知悉，不建議套用）

- `Exploded Axonometric Drawing`／`urban design` 相關的爆炸圖詞彙：屬都市設計／建築表現法範疇，與如菓住宅室內案型不符，只記錄來源不建議收錄。
- `colorful, modern furniture`（easy-peasy.ai 範例原句）：與如菓品牌調性（專業溫潤、不浮誇）衝突，不建議照抄，模式二家具描述仍照如菓既有風格詞走。
